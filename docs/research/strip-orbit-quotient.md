# Exact symmetry quotient for the checkerboard-strip transfer

This optimization changes `scripts/solve/path_bound.py`, which supplies the
rigorous bound used to choose the CRT moduli. It compresses the upper-bound
transfer, not the main Grid-FP path-counting state space.

## Construction and proof

Fix a positive strip height h. Let S be its 2^h binary columns, and let
A(x,y) be 1 exactly when adjacent columns x,y contain no checkerboard 2×2
square. Define two permutations:

- C complements every bit.
- R reverses the order of the h bits.

Both are involutions, and they commute. They generate the four transformations
I, C, R, CR, although some may act identically at small heights.

**Compatibility is invariant.** Complementing both columns switches the two
forbidden checkerboards. Reflecting both columns sends each adjacent row pair
to another adjacent row pair and reverses the top/bottom entries, again
preserving the set of the two forbidden checkerboards. Therefore
A(gx,gy)=A(x,y) for each transformation g.

Partition S into orbits O₁,…,Oₘ and choose a representative rᵢ from each orbit.
Use the weighted quotient matrix

\[
B_{ij}=\sum_{y\in O_j} A(r_i,y).
\]

**The weight is independent of the representative.** If x=g rᵢ, then g is a
bijection of Oⱼ onto itself, so

\[
\sum_{y\in O_j} A(x,y)
=\sum_{z\in O_j} A(g r_i,g z)
=\sum_{z\in O_j} A(r_i,z)=B_{ij}.
\]

Let fₖ(x) count valid continuations with k further columns after x. Then
f₀(x)=1 and fₖ₊₁(x)=Σᵧ A(x,y)fₖ(y). Define v₀(i)=1 and
vₖ₊₁(i)=Σⱼ Bᵢⱼvₖ(j). Induction proves **fₖ(x)=vₖ(i) for every x∈Oᵢ**:
the base is constant, and the inductive step follows by partitioning the sum
over y into orbits and applying the representative-independence identity.
Consequently the exact h×w count is

\[
\sum_{x\in S} f_{w-1}(x)=\sum_i |O_i|v_{w-1}(i).
\]

This is equality of integers for every positive h,w, with no numerical
approximation. Orbits can have different sizes: multiplying by |Oᵢ| in the
final sum and retaining Bᵢⱼ multiplicities are essential. Simply dividing the
original answer or transition counts by four would be incorrect.

## State reduction

Burnside's counting identity gives, for h>0,

\[
m=\frac{2^h+2^{\lceil h/2\rceil}
 +\mathbf{1}_{2\mid h}2^{h/2}}4.
\]

The terms count columns fixed by I, R and CR; C has no fixed column.
At h=9 this is **512 → 136 states**. Each quotient edge has integer weight
between zero and four. Transition construction evaluates compatibility for
m·2^h column pairs rather than 2^(2h), and each further column uses at most
m² weighted edges. The implementation deliberately retains the existing
local compatibility predicate so this change isolates the mathematical
quotient from bit-level predicate optimizations.

## Machine-checked part and implementation boundary

`formal/OneesanFormal/OrbitTransfer.lean` proves:

- `symmetric_of_four`: two orbit-preserving compatibility automorphisms and a
  representative among I,C,R,CR give the required symmetric partition.
- `quotient_weighted_sum`: the grouped weighted sum equals the original sum.
- `counts_exact`: every iterate of the quotient agrees with the full transfer.
- `total_exact`: orbit-size weighting recovers the full integer count.

These general theorems compile in Lean without `sorry`, `admit`, custom axioms
or finite-width extrapolation. The specific complement/reflection invariance
and representative construction are proved above; they are application
hypotheses of the Lean theorem, not a mechanized refinement of the Python
bit-string implementation. Tests check that implementation correspondence,
including arbitrary nonuniform orbit values, orbit sizes, an independent
uncompressed verifier, brute-force small matrices and the existing formal
9×27 strip constant. Thus the boundary of the machine-checked claim is explicit.

## Measurements and practical scope

Alternating seven measured executions after one warm-up, computing the entire
n=27 upper bound afresh:

| Implementation | Median seconds |
|---|---:|
| Original full transfer | 0.244480 |
| Weighted symmetry quotient | 0.067560 |

This is about **3.62× faster for upper-bound construction**. Raw samples are in
`docs/results/strip-orbit-quotient-2026-09-05.json`. The exact bound, partition
`[9,9,9]`, 633-bit size and required 20 CRT primes remain unchanged. This
measurement does not imply a 3.62× speedup of the CUDA path-counting run.

## Rejected suffix-height pruning

Bounding a state's height by the number of rows remaining is not valid for
this recurrence. At width eight, `LLLRRRRN` has height four but reaches the
last-row support after a single ordinary row: include cells p=4 and p=2,
with the other choices excluded (including the mandatory blocked exclusions).
The resulting packed state is 25600, the first-row state generated by mask 32.
Thus it has a completion with two rows remaining despite height four.
`tests/gridfp_reverse_test.cpp` retains this counterexample to prevent adopting
the tempting but incorrect pruning rule.
